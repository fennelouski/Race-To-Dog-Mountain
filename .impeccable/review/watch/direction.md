# Minimal paged Apple Watch game

User asks to build the game for watchOS, then explicitly requests a simpler wrist UI with fewer options, modular pagination and almost no visible words. The clock must not crowd play.

Inherit pine, cream, gold and mint from the alpine game. Home uses a mountain emblem and Play glyph, with Settings on a second native vertical page. Game pages separate Moves, Board, Score/replay and Settings, navigated with Crown or vertical swipe. Fixed 4 × 4 Classic; human first against computer player 2. Keep all sixteen numbered human portraits as difficulty choices. Remove board-size, role, chat and biography controls.

Moves use a direction glyph and row/column index, then two columns of large points-only number buttons. Coordinate/route details remain in VoiceOver labels and on the read-only full-board page. A thin 4-point gold/mint/muted-remaining points bar sits in its own footer below the scroll area. Native clock keeps clear top space; public overlay-hidden preference was tested and did not hide it, so no private API. Score page uses person/portrait glyphs and numeric totals plus remaining-board points. Settings, difficulty, replay, result and exit use icons/numerals. Only the native exit confirmation keeps necessary explanatory text. Full descriptive accessibility labels/hints remain.

Every move saves locally; relaunch resumes. Computer pauses inactive/dimmed, on any page except Moves, during replay and exit confirmation. Native haptics, minimum44-point controls, Dynamic Type and reduced-motion guards remain. Static alpine home backdrop; plain pine game. Physical Watch battery, haptic comfort, live VoiceOver and largest accessibility text remain unverified hardware/runtime checks. No approved comp; code-led native adaptation of the existing identity.
